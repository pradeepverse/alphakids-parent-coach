# AGENTS.md: guide for coding agents working on this repo

This file is for coding agents (Claude Code, Codex, Cursor, …) changing **this codebase**.
The *coach's own* runtime persona lives in [`coach/AGENTS.md`](coach/AGENTS.md); don't confuse the two.

## What this is
A **static** Next.js 16 app (`output: "export"`, deployed to GitHub Pages) where a parent
describes a concern in English or Urdu and an LLM coach replies with a short, structured,
safe plan plus a check-in. The coach is a LangChain **deepagents** agent that runs **in the
browser**, driven by markdown skills. There is no server and no database.

Run `typecheck`, `lint`, `test:safety` and `build` before calling a change done.

## Layout
```
coach/AGENTS.md                 coach persona + non-negotiable rules (loaded as deepagents memory)
coach/skills/<name>/SKILL.md    skills: everyday-coaching, crisis-escalation, boundaries, urdu-replies
scripts/bundle-coach.mjs        bundles coach/**/*.md -> src/generated/coach-files.ts (pre dev/build)
scripts/test-safety.ts          regression cases for the deterministic crisis check
src/lib/safety.ts               deterministic crisis pre-check (EN, Urdu script, Roman Urdu)
src/lib/coach.ts                in-browser deepagent (deepagents/browser + ChatAnthropic)
src/lib/fallbacks.ts            fixed crisis reply + labelled demo replies (no-key mode)
src/lib/types.ts                CoachReply zod schema (the reply contract)
src/components/                 CoachChat (chat + settings), ReplyCard (structured reply UI)
src/stubs/                      browser stand-ins for Node-only imports (ws, node:async_hooks)
docs/ARCHITECTURE.md            architecture + safety design;  docs/DESIGN.md: UI design
```

## Rules you must not break
1. **Safety layers are independent.** `checkSafety()` runs before the model and can only
   *raise* risk to `crisis`, never lower it. If the model call fails on a flagged message,
   `crisisReply()` must still be shown. Don't route crisis handling through the model alone.
2. **The emergency banner is code, not model output** (`EmergencyBanner` in `ReplyCard.tsx`).
   Never render model-written text as the emergency instructions, and never hard-code
   country-specific hotline numbers (product decision: generic "local emergency number").
3. **Behaviour changes go in markdown first.** Tone, steps and examples belong in
   `coach/AGENTS.md` or a `SKILL.md`. Change TS only for structure or safety.
4. **Reply contract** is `CoachReplySchema` in `src/lib/types.ts`. If you change it, update
   the skills, `fallbacks.ts`, and `ReplyCard.tsx` together.
5. **Never commit or bake in API keys.** No `NEXT_PUBLIC_*` key variables: a static build would
   publish them. Keys are entered by the user at runtime and kept in `sessionStorage`.
6. When you add a crisis keyword, add a case to `scripts/test-safety.ts` (both a must-trigger
   and a nearby must-not-trigger case where possible).
7. Keep it static: no API routes, server actions, or anything needing a Node server.
8. Urdu: right-to-left text uses `dir="rtl"`/`dir="auto"` and the `.urdu`/`lang="ur"` font rules.
   Test with Urdu script **and** Roman Urdu.

## Gotchas
- `src/generated/` is git-ignored and regenerated by `predev`/`prebuild`; run
  `node scripts/bundle-coach.mjs` if your editor complains it's missing.
- deepagents pulls in langsmith/langgraph code that imports Node built-ins; the aliases in
  `next.config.ts` (`turbopack.resolveAlias`) point them at `src/stubs/`. Keep them.
- GitHub Pages serves under `/<repo>`; the workflow sets `NEXT_PUBLIC_BASE_PATH`.
